먼저 알아야 할 것들

Matplotlib의 구조를 이해하면 API가 훨씬 자연스럽게 읽힙니다. Figure → Axes → Artist 계층, OO vs pyplot 차이, 렌더링 파이프라인 이 세 가지가 핵심입니다.

① Figure · Axes · Artist 계층

Matplotlib의 모든 것은 세 계층으로 이루어집니다. Figure는 캔버스(창 전체), Axes는 그 안의 개별 플롯 영역(좌표계), Artist는 선·점·텍스트 등 실제로 그려지는 모든 객체입니다. plt.subplots()는 Figure와 Axes를 동시에 생성하는 가장 흔한 진입점입니다.

예시 코드

import matplotlib.pyplot as plt
import numpy as np

# 가장 기본적인 OO 패턴
fig, ax = plt.subplots()          # Figure + Axes 동시 생성
ax.plot([1, 2, 3], [4, 5, 6])     # Axes에 Artist 추가
ax.set_title("간단한 선 그래프")
plt.show()

# 여러 개의 Axes
fig, axes = plt.subplots(2, 2, figsize=(10, 8))
print(type(fig))    # matplotlib.figure.Figure
print(type(axes))   # numpy.ndarray (shape: 2x2)
<class 'matplotlib.figure.Figure'> <class 'numpy.ndarray'>

② OO 방식 vs pyplot 방식

pyplot 방식은 plt.plot()처럼 전역 상태를 사용합니다. 빠른 탐색에는 편하지만 복잡한 그림에서는 "현재 Axes"가 무엇인지 헷갈립니다. OO 방식은 ax.plot()처럼 명시적으로 대상 Axes를 지정하므로 예측 가능하고 재사용이 쉽습니다.

언제 pyplot을 써도 되나? Jupyter 노트북에서 혼자 빠르게 확인하는 탐색형 시각화라면 plt.plot()도 충분합니다. 하지만 함수 안에서 그래프를 그리거나, 서브플롯이 2개 이상이거나, 코드를 재사용할 예정이라면 반드시 OO 방식을 쓰세요.

#01

plt.subplots()

pyplot

Figure 하나와 Axes 하나(또는 여러 개)를 동시에 생성합니다. Matplotlib에서 가장 많이 쓰이는 진입점입니다.

시그니처

plt.subplots(nrows=1, ncols=1, *, sharex=False, sharey=False, squeeze=True, figsize=None, dpi=None, **kwargs)

파라미터

파라미터설명기본값 / 옵션
nrows행 방향 서브플롯 개수1
ncols열 방향 서브플롯 개수1
sharexX축 공유 여부. 'col'이면 같은 열끼리, 'row'면 같은 행끼리, True면 전체False
shareyY축 공유 여부False
squeezeAxes가 1개면 배열 대신 단일 객체로 반환할지 여부True
figsizeFigure 크기 (가로인치, 세로인치)None (rcParams 기본값)
dpi해상도 (dots per inch)None (rcParams 기본값≈100)

예시 코드

import matplotlib.pyplot as plt
import numpy as np

x = np.linspace(0, 2*np.pi, 100)

# 1행 2열 서브플롯, Y축 공유
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(10, 4), sharey=True)
ax1.plot(x, np.sin(x), label='sin')
ax1.set_title('Sine')
ax2.plot(x, np.cos(x), color='#c0396b', label='cos')
ax2.set_title('Cosine')
plt.tight_layout()

# 2행 2열, 전체 배열로 받기
fig2, axs = plt.subplots(2, 2, squeeze=False)
print(axs.shape)   # numpy 배열로 다루기 편함
(2, 2)
squeeze=False를 항상 명시하면 nrows나 ncols가 1이 되는 경우에도 항상 2D ndarray를 받으므로 반복문에서 axs[i, j]로 균일하게 접근할 수 있습니다.

시그니처

plt.figure(num=None, figsize=None, dpi=None, facecolor=None, edgecolor=None, frameon=True, clear=False, **kwargs)

파라미터

파라미터설명기본값
numFigure 번호 또는 이름(문자열). 같은 번호/이름이면 기존 Figure 재사용None (자동 증가)

# 고해상도 Figure 생성 (출판/저장용)
fig = plt.figure(figsize=(12, 8), dpi=150)
ax = fig.add_subplot(111)
ax.plot([1, 2, 3], [4, 5, 6])

# Figure 이름으로 재사용

print(fig_a is fig_b)  # True

ax.scatter()

OO

산점도를 그립니다. plot과 달리 각 점마다 크기와 색상을 개별 지정할 수 있어 3번째·4번째 변수를 인코딩하는 데 유용합니다.

ax.scatter(x, y, s=None, c=None, marker='o', cmap=None, norm=None, alpha=None, linewidths=None, **kwargs)

주요 파라미터

파라미터설명기본값
x, y 필수좌표 배열—

예시 코드

rng = np.random.default_rng(42)
x = rng.normal(0, 1, 200)
y = x * 0.8 + rng.normal(0, 0.5, 200)
size = rng.uniform(20, 200, 200)   # 크기로 3번째 변수 인코딩

fig, ax = plt.subplots(figsize=(7, 5))
sc = ax.scatter(x, y, s=size, c=color, cmap='viridis', alpha=0.7)
fig.colorbar(sc, ax=ax, label='4번째 변수')
ax.set_xlabel('x'); ax.set_ylabel('y')
scatter는 plot보다 렌더링이 무겁습니다. 데이터 포인트가 10만 개 이상이면 ax.plot(x, y, '.', ms=1)이나 hexbin을 고려하세요.

  • 두 연속 변수 사이에 상관관계가 있는지 파악할 때
  • 데이터 포인트가 군집을 이루는지 확인할 때
  • 이상값(outlier)의 위치를 탐색할 때
데이터 포인트가 수만 개를 넘으면 점이 겹쳐 분포를 알 수 없습니다. hexbin이나 hist2d로 밀도 기반 시각화를 쓰세요.

  • 각 범주의 절대량을 비교할 때

n = 100

④ 색상 주기 (Color Cycle) 활용

여러 선을 루프로 그릴 때 색상이 자동으로 순환됩니다. 주기를 제어하거나 특정 팔레트를 쓰는 방법입니다.

import matplotlib.cm as cm

fig, ax = plt.subplots(figsize=(9, 5))

# 방법 1: 자동 색상 주기
for i in range(5):
    ax.plot(np.random.randn(50).cumsum(), label=f'Series {i}')

# 방법 2: 컬러맵에서 색상 추출
colors = cm.viridis(np.linspace(0, 1, 5))
for i, c in enumerate(colors):
    ax.plot(np.random.randn(50).cumsum(), color=c, label=f'CM {i}')

# 방법 3: 색상 주기 직접 설정
ax.set_prop_cycle(color=['#3c63b8', '#c0396b', '#2a8a4a', '#c26a06'])

⑤ 미니멀 스타일 (스파인 제거)

불필요한 테두리(spine)를 제거하면 데이터에 집중할 수 있는 깔끔한 그림이 됩니다.

fig, ax = plt.subplots(figsize=(8, 4))
ax.plot(np.random.randn(100).cumsum(), lw=2)

# 위·오른쪽 테두리 제거
ax.spines['top'].set_visible(False)
ax.spines['right'].set_visible(False)

# 왼쪽 축 시작점을 데이터 범위로 제한
ax.spines['left'].set_bounds(ax.get_yticks()[0], ax.get_yticks()[-1])

# tick을 바깥으로 (세련된 느낌)
ax.tick_params(direction='out', length=5)

⑥ 확대 삽입 플롯 (inset_axes)

주 그래프 안에 확대된 영역을 삽입합니다. 관심 구간을 강조하는 논문 그림에 자주 쓰입니다.

from mpl_toolkits.axes_grid1.inset_locator import inset_axes, mark_inset

x = np.linspace(0, 10, 500)
y = np.sin(x) + np.random.randn(500) * 0.1

fig, ax = plt.subplots(figsize=(9, 5))
ax.plot(x, y)
ax.set_title('전체 신호')

# 삽입 플롯: 위치 (Axes 좌표), 크기
axins = inset_axes(ax, width='40%', height='40%', loc='upper right')
axins.plot(x, y, lw=1)
axins.set_xlim(4, 6)    # 확대 구간
axins.set_ylim(-1.2, 1.2)
axins.set_xticklabels([])
mark_inset(ax, axins, loc1=2, loc2=4, fc='none', ec='0.5')
