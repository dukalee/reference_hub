WSL 설치

이 문서의 모든 명령어는 Windows의 WSL2(Windows Subsystem for Linux) + Ubuntu 환경에서 직접 실행하고 검증했습니다. Linux나 macOS를 쓴다면 이 절은 건너뛰어도 됩니다.

Windows에 Ubuntu 설치하기

Windows 10(2004 이상) / Windows 11에서는 명령어 한 줄로 WSL과 기본 배포판(Ubuntu)이 함께 설치됩니다. 관리자 권한 PowerShell 또는 명령 프롬프트에서 실행하세요.

설치

wsl --install
설치가 끝나면 PC를 재부팅해야 합니다. 재부팅 후 자동으로 Ubuntu 터미널이 열리고, 사용할 Linux 사용자 이름과 비밀번호를 만들라는 안내가 나옵니다 — 이 비밀번호가 이후 sudo 명령을 쓸 때 필요한 비밀번호입니다.

특정 배포판을 지정해서 설치

wsl --install -d Ubuntu

설치 확인 · 실행

wsl -l -v          # 설치된 배포판과 버전(WSL1/2) 확인
wsl -d Ubuntu       # Ubuntu 셸 진입
NAME STATE VERSION * Ubuntu Running 2
이미 WSL은 있는데 배포판만 없다면 wsl --list --online으로 설치 가능한 배포판 목록을 보고 wsl --install -d <배포판명>으로 추가할 수 있습니다. 기존 설치를 업데이트하려면 wsl --update를 사용하세요.

먼저 알아야 할 4가지

개별 명령어를 외우기 전에 이 네 가지를 이해하면 나머지는 대부분 유추됩니다.

① 셸(shell)과 프롬프트 — 명령어의 구조

터미널을 열면 보이는 $ 또는 user@host:~$ 같은 표시를 프롬프트라고 합니다. 그 뒤에 입력하는 한 줄은 대부분 명령어 옵션(플래그) 인자 구조를 따릅니다.

예시

user@DESKTOP:~/project$ ls -l data
                         ↑명령어  ↑옵션(-)  ↑인자
구성요소설명예
명령어실행할 프로그램 이름ls, grep
옵션(플래그)- 하나 + 짧은 문자, 또는 -- + 긴 이름. 여러 개를 묶어 -la처럼 쓸 수 있음-l, --all, -la
인자명령어가 실제로 다룰 대상(파일·경로·문자열)data, *.txt
man <명령어>는 그 명령어의 모든 옵션을 알려주는 사전입니다. 옵션이 기억나지 않으면 외우지 말고 man부터 찾는 습관을 들이세요.

② 경로 — 절대경로 · 상대경로 · 홈 디렉터리

Linux의 모든 파일은 /(루트)에서 시작하는 하나의 나무 구조에 속합니다. 경로는 절대경로(/부터 시작)와 상대경로(현재 위치 기준)로 나뉩니다.

예시 코드

cd ~                 # 홈 디렉터리로
pwd
cd refdemo/project   # 상대경로
pwd
cd /tmp               # 절대경로
pwd
cd -                  # 바로 직전 디렉터리로
pwd
cd ..                 # 한 단계 위로
pwd
/home/user /home/user/refdemo/project /tmp /home/user/refdemo/project /home/user/refdemo

③ 표준입출력 — stdin · stdout · stderr

모든 명령어는 기본으로 3개의 통로를 갖습니다. 표준입력(0)으로 받고, 표준출력(1)으로 정상 결과를 내보내고, 표준에러(2)로 에러 메시지를 따로 내보냅니다. |·>·2> 같은 리다이렉션은 전부 이 세 통로를 다시 연결하는 것입니다(F. 파이프와 리다이렉션 참고).

예시 코드

# 정상 출력과 에러 출력이 각자 다른 통로로 나간다
ls existing_dir nope_dir 1> out.log 2> err.log
cat out.log
cat err.log
existing_dir: ls: cannot access 'nope_dir': No such file or directory

④ 권한 표기법 — rwxr-xr-x 읽는 법

ls -l 맨 앞 10글자는 파일 타입 1글자 + 소유자(u)·그룹(g)·기타(o) 각 3글자(r=읽기, w=쓰기, x=실행)로 구성됩니다. 3글자씩을 2진수로 보면 8진수 한 자리가 됩니다.

예시 코드

ls -l run.sh
chmod 644 run.sh   # rw-r--r-- : 소유자만 쓰기 가능
ls -l run.sh
-rwxr-xr-x 1 user user 8 Sep 4 09:29 run.sh -rw-r--r-- 1 user user 8 Sep 4 09:29 run.sh

위치와 탐색

3 commands

지금 내가 어디에 있고 무엇이 있는지 확인하는, 가장 먼저 몸에 배는 세 개입니다.

#03

pwd

현재 작업 디렉터리의 절대경로를 출력합니다. Print Working Directory의 약자.

예시 코드

cd ~/refdemo/project
pwd
/home/user/refdemo/project
#01

cd

디렉터리를 이동합니다. 인자 없이 cd만 치면 홈으로, cd -는 직전 디렉터리로 돌아갑니다.

시그니처

cd [경로]
형태이동 위치
cd / cd ~홈 디렉터리
cd -바로 이전 디렉터리
cd ..한 단계 상위
cd /경로절대경로로 이동

예시 코드

cd /tmp
pwd
cd -
pwd
/tmp /home/user/refdemo/project
#02

ls

디렉터리 내용을 나열합니다. 옵션 없이 쓰면 숨김파일(.로 시작)은 보이지 않습니다.

시그니처

ls [옵션] [경로]
옵션설명
-a숨김파일까지 전부(., .. 포함)
-l긴 목록(권한·소유자·크기·수정일)
-h-l과 함께, 크기를 사람이 읽기 쉬운 단위로
-la / -al-l과 -a를 묶어서

예시 코드

ls
ls -a
ls -l
docs src . .. .env docs src total 8 drwxr-xr-x 2 user user 4096 Sep 4 09:29 docs drwxr-xr-x 2 user user 4096 Sep 4 09:29 src
1열이 권한, 3·4열이 소유자·그룹, 5열이 바이트 크기입니다. 폴더인지 파일인지는 맨 앞 글자로 구분합니다 — d는 디렉터리, -는 일반 파일.

파일과 폴더 조작

6 commands

만들고, 복사하고, 옮기고, 지우는 여섯 개. rm은 휴지통이 없다는 점만 기억하세요.

#09

mkdir

새 디렉터리를 만듭니다. -p를 쓰면 중간 경로가 없어도 한 번에 만들고, 이미 있어도 에러 없이 넘어갑니다.

시그니처

mkdir [-p] 디렉터리...

예시 코드

mkdir data
mkdir -p archive/2024/reports   # 중간 폴더까지 한 번에
ls
archive data project

touch

빈 파일을 만들거나, 이미 있는 파일이면 수정 시각만 지금으로 갱신합니다.

예시 코드

touch data/notes.txt
ls data
notes.txt
#06

cp

파일이나 디렉터리를 복사합니다. 디렉터리를 통째로 복사하려면 -r(재귀)이 필수입니다.

시그니처

cp [-r] 원본 대상

예시 코드

cp data/notes.txt data/notes_backup.txt
ls data
cp -r project project_copy   # 폴더 전체 복사엔 -r 필수
ls
notes.txt notes_backup.txt archive data project project_copy
-r 없이 디렉터리를 cp하면 cp: -r not specified; omitting directory 'project' 에러가 납니다.
#07

mv

파일을 이동하거나 이름을 바꿉니다. Linux에는 별도의 rename 명령이 없고 같은 폴더 안에서 mv하면 그게 이름 변경입니다.

예시 코드

mv data/notes_backup.txt data/notes_old.txt
ls data
notes.txt notes_old.txt
#08

rm

주의

파일을 삭제합니다. 디렉터리를 지우려면 -r, 확인 없이 강제로 지우려면 -f. 휴지통을 거치지 않고 즉시 사라집니다.

시그니처

rm [-r] [-f] 대상...

예시 코드

rm data/notes_old.txt
rm -r project_copy
ls
archive data project
rm -rf / 같은 실수는 되돌릴 수 없습니다. rm -rf 변수명/처럼 변수가 비어버리면 의도치 않게 루트를 지우는 사고가 실제로 일어납니다 — 스크립트에서 변수로 경로를 만들 때는 항상 값이 비어있지 않은지 확인하세요.

rmdir

비어 있는 디렉터리만 지웁니다. 안에 뭐가 있으면 에러가 나서, 실수로 내용물째 지우는 사고를 막아줍니다.

예시 코드

mkdir empty_dir
rmdir empty_dir
ls
archive data project
내용물까지 통째로 지우고 싶다면 rmdir이 아니라 rm -r 디렉터리를 쓰세요.

내용 보기와 편집

4 commands

파일을 열어보고 고치는 방법들. 전체를 쏟아낼지, 페이지 단위로 볼지, 편집기로 열지를 고릅니다.

#04

cat

파일 내용 전체를 화면에 그대로 쏟아냅니다. 짧은 파일 확인, 그리고 리다이렉션과 조합해 파일을 합칠 때도 씁니다.

예시 코드

cat project/src/main.py
def main(): print('hello')

less · more

긴 파일을 화면 단위로 끊어서 보여주는 페이저(pager)입니다. 로그 파일처럼 cat으로 쏟아내면 스크롤이 다 날아가는 파일에 씁니다.

시그니처

less 파일 more 파일
도구특징
more앞으로만 스크롤 가능한 구형 페이저
less위아래 자유 스크롤, /검색어로 파일 내 검색, q로 종료 — 사실상 more의 상위 호환
less·more는 화면을 그대로 차지하는 대화형 프로그램이라 터미널 캡처로 결과를 보여줄 수 없습니다. 직접 less data/access.log를 실행해서 Space로 다음 페이지, q로 종료해보세요.
#05

head · tail

파일의 앞부분(head) 또는 뒷부분(tail)만 봅니다. 기본은 10줄, -n으로 줄 수를 지정합니다.

시그니처

head [-n 줄수] 파일 tail [-n 줄수] 파일 tail -f 파일 # 실시간으로 추가되는 내용을 계속 보여줌

예시 코드

seq 1 20 > data/numbers.txt
head -n 5 data/numbers.txt
tail -n 5 data/numbers.txt
1 2 3 4 5 16 17 18 19 20
tail -f app.log는 실시간 로그를 지켜볼 때 표준입니다. Ctrl+C로 종료합니다.

nano · vim

터미널 안에서 파일을 편집하는 에디터입니다. nano는 화면 하단에 단축키가 항상 보여 입문에 부담이 적고, vim은 학습 곡선은 가파르지만 서버 관리자 대부분이 기본으로 씁니다.

시그니처

nano 파일 vim 파일
에디터저장 후 종료종료(저장 안 함)
nanoCtrl+O → Enter, 그 다음 Ctrl+XCtrl+X 후 저장 여부에 N
vimEsc 후 :wqEsc 후 :q!
vim을 처음 실행하면 글자를 입력해도 반응이 없어 당황하기 쉽습니다 — 시작은 명령 모드이고, i를 눌러야 입력 모드로 들어가 타이핑할 수 있습니다. 빠져나가고 싶으면 Esc 후 :q!.

검색

3 commands

파일을 찾을 땐 find, 파일 안 내용을 찾을 땐 grep, 명령어 자체의 위치를 찾을 땐 which.

#10

find

디렉터리 트리를 훑으며 이름·타입·크기·수정일 등 조건에 맞는 파일을 찾습니다.

시그니처

find 경로 -name "패턴" find 경로 -type f|d

예시 코드

find . -name "*.py"
find . -type d
./project/src/utils.py ./project/src/main.py . ./data ./archive ./archive/2024 ./archive/2024/reports ./project ./project/src ./project/docs
파일을 찾자마자 바로 처리하고 싶다면 find . -name "*.log" -delete나 find . -name "*.py" -exec grep -l TODO {} \;처럼 -exec/-delete를 붙이세요.
#05

grep

파일(또는 표준입력) 안에서 패턴과 일치하는 줄을 찾습니다. 정규식을 지원하며, 로그 분석·코드 검색의 기본기입니다.

시그니처

grep [옵션] "패턴" 파일...
옵션설명
-n줄 번호 표시
-r디렉터리를 재귀적으로 검색
-i대소문자 무시
-v패턴과 일치하지 않는 줄만
-c일치한 줄 개수만

예시 코드

grep -n "import" project/src/utils.py
grep -rn "print" project
1:import os project/src/main.py:2: print('hello')

which

어떤 명령어가 어느 실행파일을 가리키는지 경로를 알려줍니다. "이 명령어가 진짜 설치돼 있나?"를 확인할 때 씁니다.

예시 코드

which python3
which ls
/usr/bin/python3 /usr/bin/ls
같은 이름의 명령어가 여러 경로에 있을 수 있습니다(예: pyenv, conda). which은 $PATH에서 가장 먼저 발견되는 것을 보여줍니다.

텍스트 가공

6 commands

로그·CSV 같은 줄 단위 텍스트를 자르고 세고 바꾸는 도구들. 서로 파이프로 이어 쓰는 게 진짜 힘입니다.

#20

sed

스트림 에디터. 가장 많이 쓰는 건 문자열 치환 s/찾을것/바꿀것/입니다.

시그니처

sed 's/찾을패턴/바꿀문자열/' 파일 sed -i 's/.../.../' 파일 # -i: 파일을 직접 수정

예시 코드

cat data/access.log
sed 's/200/OK/' data/access.log
192.168.0.1 GET /index.html 200 192.168.0.2 GET /about.html 200 192.168.0.1 POST /login 401 192.168.0.3 GET /index.html 200 192.168.0.2 GET /index.html 404 192.168.0.1 GET /index.html OK 192.168.0.2 GET /about.html OK 192.168.0.1 POST /login 401 192.168.0.3 GET /index.html OK 192.168.0.2 GET /index.html 404
기본적으로 sed는 결과를 화면에만 출력하고 원본 파일은 그대로입니다. 파일을 실제로 바꾸려면 -i를 붙이세요 — 되돌릴 수 없으니 먼저 -i 없이 결과를 확인하는 습관을 들이세요.
#21

awk

줄을 공백 기준으로 $1, $2 … 필드로 쪼개 다룹니다. 로그에서 특정 컬럼만 뽑아낼 때 표준입니다.

시그니처

awk '{print $1, $4}' 파일

예시 코드

# $1 = IP, $4 = 상태코드
awk '{print $1, $4}' data/access.log
192.168.0.1 200 192.168.0.2 200 192.168.0.1 401 192.168.0.3 200 192.168.0.2 404
awk -F,처럼 -F로 구분자를 바꾸면 CSV도 그대로 처리할 수 있습니다. 조건까지 걸고 싶으면 awk '$4==200 {print $1}'처럼 씁니다.

cut

awk보다 단순하게, 구분자 기준으로 특정 필드(열)만 잘라냅니다.

시그니처

cut -d '구분자' -f 필드번호 파일

예시 코드

cut -d ' ' -f 1 data/access.log
192.168.0.1 192.168.0.2 192.168.0.1 192.168.0.3 192.168.0.2

sort · uniq

sort는 줄 단위로 정렬하고, uniq는 연속된 중복 줄을 제거합니다. 그래서 uniq는 거의 항상 sort 뒤에 붙습니다.

시그니처

sort [-u] [-n] [-r] 파일 ... | uniq [-c]

예시 코드

cut -d ' ' -f 1 data/access.log | sort
cut -d ' ' -f 1 data/access.log | sort -u   # -u: 정렬하며 중복 제거
cut -d ' ' -f 1 data/access.log | sort | uniq -c   # -c: 개수까지
192.168.0.1 192.168.0.1 192.168.0.2 192.168.0.2 192.168.0.3 192.168.0.1 192.168.0.2 192.168.0.3 2 192.168.0.1 2 192.168.0.2 1 192.168.0.3
uniq는 정렬돼 있지 않으면 제대로 동작하지 않습니다 — 1 2 1에 uniq만 걸면 그대로 1 2 1이 나옵니다. 항상 sort | uniq 순서로 쓰세요.

wc

줄 수(-l)·단어 수(-w)·바이트 수(-c)를 셉니다. 파이프 끝에서 "결과가 몇 개인지"만 알고 싶을 때 자주 씁니다.

예시 코드

wc -l data/access.log
wc -l < data/access.log   # 파일명 없이 숫자만
5 data/access.log 5

tr

문자 단위로 치환하거나 삭제합니다. 파일이 아니라 표준입력만 받으므로 항상 파이프와 함께 씁니다.

시그니처

... | tr '집합1' '집합2' ... | tr -d '집합'

예시 코드

파이프와 리다이렉션

4 items

표준입출력의 통로를 다시 연결하는 기호들. Linux 명령어를 조합하는 힘의 원천입니다.

#16

| (파이프)

왼쪽 명령의 표준출력을 오른쪽 명령의 표준입력으로 그대로 연결합니다. 중간 파일 없이 명령어를 이어 붙이는 핵심 도구입니다.

예시 코드

cat data/access.log | grep 200 | wc -l
3

> · >> (출력 리다이렉션)

>는 표준출력을 파일로 보내며 파일을 덮어씁니다. >>는 같은 일을 하되 기존 내용 뒤에 이어붙입니다.

예시 코드

echo "192.168.0.9 GET /new.html 200" > data/new.log
cat data/new.log
echo "192.168.0.9 GET /new2.html 200" >> data/new.log
cat data/new.log
192.168.0.9 GET /new.html 200 192.168.0.9 GET /new.html 200 192.168.0.9 GET /new2.html 200
>는 기존 파일을 확인 없이 통째로 지웁니다. cmd > input.txt처럼 입력과 출력이 같은 파일이면 파일이 빈 채로 잘려나갈 수 있으니 주의하세요.

< (입력 리다이렉션)

파일 내용을 표준입력으로 흘려보냅니다. cat 파일 | 명령어와 결과는 비슷하지만 cat 프로세스 하나를 아낍니다.

예시 코드

wc -l < data/access.log
5

2> (에러 리다이렉션)

표준에러(파일 디스크립터 2번)만 따로 파일로 보냅니다. 정상 출력과 에러를 분리해서 로그를 남길 때 씁니다.

예시 코드

ls /no/such/dir 2> data/err.log
cat data/err.log
ls: cannot access '/no/such/dir': No such file or directory
에러까지 한 파일에 합치고 싶으면 cmd > out.log 2>&1(순서 중요: 먼저 stdout을 파일로 돌린 뒤, stderr을 stdout이 가리키는 곳으로). 최신 셸에서는 cmd &> out.log로도 같은 효과를 낼 수 있습니다.

2 commands

여러 파일을 하나로 묶거나(아카이브), 용량을 줄이는(압축) 도구들.

#13

tar

여러 파일·디렉터리를 하나의 아카이브 파일로 묶습니다. z 옵션을 더하면 gzip으로 압축까지 동시에 합니다(.tar.gz).

시그니처

tar czf 결과.tar.gz 대상 # c=생성 z=gzip f=파일명 tar xzf 아카이브.tar.gz -C 대상폴더 # x=압축해제 tar tzf 아카이브.tar.gz # t=목록만 확인(해제 안 함)

예시 코드

tar czf project_backup.tar.gz project
ls -l project_backup.tar.gz
tar tzf project_backup.tar.gz
-rw-r--r-- 1 user user 323 Sep 4 09:29 project_backup.tar.gz project/ project/src/ project/src/utils.py project/src/main.py project/.env project/docs/ project/docs/readme.md
mkdir restore
tar xzf project_backup.tar.gz -C restore
find restore -type f
restore/project/src/utils.py restore/project/src/main.py restore/project/.env restore/project/docs/readme.md
옵션 순서를 외우기 어렵다면 "압축해서(z) 파일로(f) 만들어라(c)/풀어라(x)"로 기억하세요. -C 대상폴더는 해제 위치를 지정합니다(생략하면 현재 위치에 풂).

gzip · gunzip

파일 하나를 압축합니다(여러 파일을 묶으려면 먼저 tar로 아카이브를 만들어야 함). 기본은 원본을 .gz로 대체합니다.

예시 코드

ls data
gzip data/access.log
ls data
access.log err.log new.log notes.txt numbers.txt access.log.gz err.log new.log notes.txt numbers.txt
gunzip data/access.log.gz
ls data
access.log err.log new.log notes.txt numbers.txt
원본을 남겨두고 압축본만 만들고 싶다면 gzip -k(keep)를 쓰세요. zip/unzip은 WSL Ubuntu에 기본 설치돼 있지 않아(sudo apt install zip unzip 필요) 이 문서에서는 실제 실행 결과를 담지 않았습니다 — 여러 파일을 하나의 .zip으로 묶고 싶을 때 쓰는 도구라는 점만 참고하세요.

uname · whoami

uname은 커널·아키텍처 정보를, whoami는 현재 로그인한 사용자 이름을 보여줍니다.

시그니처

uname -a # 전체 정보 uname -r # 커널 버전만 whoami

예시 코드

uname -a
whoami
Linux DESKTOP-58TV9FU 6.18.33.2-microsoft-standard-WSL2 #1 SMP PREEMPT_DYNAMIC Thu Jun 18 21:54:43 UTC 2026 x86_64 GNU/Linux user
출력 중 microsoft-standard-WSL2 부분이 바로 지금 이 문서를 검증한 환경이 WSL2라는 증거입니다. 순수 Linux 서버라면 5.15.0-...-generic 같은 배포판 고유 커널명이 나옵니다.

#22

echo

문자열이나 변수 값을 화면에 출력합니다. 디버깅·스크립트에서 값 확인용으로 가장 자주 쓰입니다.

예시 코드

echo "Hello, WSL!"
echo $HOME
Hello, WSL! /home/user
#23

export

셸 변수를 환경변수로 승격시켜, 이 셸에서 실행하는 모든 자식 프로세스가 그 값을 물려받게 합니다.

시그니처

export 변수명=값

예시 코드

export MY_NAME="claude"
echo $MY_NAME
bash -c 'echo child sees: $MY_NAME'   # 자식 프로세스에서도 보임
claude child sees: claude
export 없이 MY_NAME="claude"만 하면 현재 셸에서만 보이고 자식 프로세스(스크립트, 하위 명령)에는 전달되지 않습니다. 매번 새 터미널에서도 유지하려면 ~/.bashrc에 export 줄을 추가하세요.
#24

alias

자주 쓰는 긴 명령어에 짧은 이름을 붙입니다.

예시 코드

alias ll='ls -la'
alias
alias ll='ls -la'
터미널을 새로 열어도 유지하려면 ~/.bashrc에 alias ll='ls -la' 줄을 추가하고 source ~/.bashrc로 반영하세요.
#25

history

지금까지 입력한 명령어 목록을 보여줍니다. !번호로 재실행하거나, Ctrl+R로 역방향 검색할 수 있습니다.

시그니처

history # 전체 기록 history | tail -20 !352 # 352번 명령 재실행
이 문서의 예시는 스크립트로 일괄 실행해서 검증했기 때문에 대화형 셸의 history에는 기록이 남지 않습니다. 직접 터미널에 명령어 몇 개를 입력한 뒤 history를 실행해서 확인해보세요.
#25

man

명령어의 공식 매뉴얼을 보여줍니다. 옵션이 기억나지 않을 때 가장 먼저 찾아야 할 곳.

예시 코드

man ls | head -6
LS(1) General Commands Manual LS(1) NAME ls - List directory contents. SYNOPSIS ls [--help] [--format] [-C] [-l|--long] ...
화면 가득 찬 매뉴얼 안에서는 /검색어로 찾고 n으로 다음 결과, q로 종료합니다. 명령어가 아니라 특정 시스템 콜·설정 파일의 매뉴얼을 볼 때는 man 5 crontab처럼 섹션 번호를 붙이기도 합니다.
