§

먼저 알아야 할 4가지

개별 메소드를 외우기 전에 이 네 가지를 이해하면 나머지는 대부분 유추됩니다. Pillow는 Image 객체 하나를 중심으로 열기·변형·저장하는 파이프라인입니다.

① Image.open()은 지연 로딩(lazy loading)

Image.open()은 파일을 여는 순간 전체 픽셀을 디코딩하지 않고 헤더(크기·모드·포맷)만 먼저 읽습니다. 실제 픽셀 데이터는 .load()를 호출하거나 .crop()·.resize()·.save()처럼 픽셀이 필요한 연산을 실행하는 시점에 디코딩됩니다.

예시 코드

from PIL import Image

with Image.open("photo.jpg") as img:
    print(img.size, img.mode, img.format)   # 이 시점엔 헤더만 읽힌 상태
    img.load()                              # 명시적으로 픽셀 디코딩
(360, 240) RGB JPEG
with 블록을 벗어나면 파일이 자동으로 닫힙니다. 블록 밖에서 이미지를 계속 써야 한다면 img = Image.open(path); img.load() 후 img.close()를 직접 호출하거나, .copy()로 메모리에 완전히 올려두세요.

② 좌표계와 박스(box) 표기

원점 (0, 0)은 좌상단이며 x는 오른쪽, y는 아래쪽으로 증가합니다. crop()·paste() 등 여러 메소드가 공유하는 box 표기는 (left, upper, right, lower) 4개 좌표 튜플이며, right·lower는 포함되지 않는 경계(우측 반개구간)입니다.

예시 코드

w, h = img.size
box = (60, 40, 260, 180)     # (left, upper, right, lower)
region = img.crop(box)
print(region.size)          # (260-60, 180-40)
(200, 140)
box의 순서는 (x1, y1, x2, y2)이지 (x, y, width, height)가 아닙니다. 너비·높이가 필요하면 right - left, lower - upper로 직접 계산하세요.

③ 컬러 모드(mode) — 채널 구성이 곧 데이터 형태

Pillow의 모든 이미지는 mode 하나로 채널 수·의미·비트 깊이가 정해집니다. 필터·합성·저장 방식이 모드에 따라 달라지므로, 원하는 연산이 안 되면 가장 먼저 img.mode부터 확인하는 것이 실무 디버깅의 기본입니다.

모드채널설명
"RGB"3채널(R,G,B)가장 흔한 컬러 사진. 알파(투명) 없음
"RGBA"4채널(R,G,B,A)알파(투명도) 채널 포함. PNG 등에서 흔함
"L"1채널8비트 흑백(그레이스케일)
"P"1채널 + 팔레트인덱스 컬러(팔레트 참조). GIF의 기본 모드
"1"1비트흑/백 이진 이미지

예시 코드

print(img.mode)              # 원본 모드 확인
rgba = img.convert("RGBA")   # 알파 채널 추가
print(rgba.mode, rgba.getbands())
RGB RGBA ('R', 'G', 'B', 'A')

④ 대부분의 메소드는 새 Image를 반환한다

crop()·resize()·rotate()·convert()·filter() 등 대부분은 원본을 건드리지 않고 새 Image 객체를 반환합니다. 결과를 쓰려면 반드시 반환값을 변수에 담아야 합니다. 반면 paste()·putpixel()·ImageDraw로 그리는 동작·thumbnail()은 원본 객체 자체를 수정하며 None을 반환합니다.

예시 코드

# 새 Image를 반환하는 계열 — 반환값을 받아야 함
small = img.resize((100, 100))   # img 자체는 그대로

# 원본을 그 자리에서 수정하는 계열 — 반환값이 None
result = img.paste(small, (0, 0))
print(result)   # None — img 자체가 이미 바뀌어 있음
None
img = img.paste(...)처럼 반환값을 다시 대입하면 img가 None이 되어버리는 실수가 흔합니다. paste/putpixel/ImageDraw 계열은 반환값을 받지 말고 그냥 호출만 하세요.

#01

Image.open()

경로(문자열/Path) 또는 파일류 객체(BytesIO 등)로부터 이미지를 엽니다. 확장자가 아니라 파일 내용을 보고 포맷을 자동 판별합니다.

시그니처

Image.open(fp, mode="r", formats=None)

파라미터

파라미터설명기본값
fp 필수파일 경로 문자열/Path 또는 파일류(file-like) 객체—
formats시도할 포맷을 제한. 예: ["JPEG", "PNG"](빠르고 안전)None(전체 시도)

예시 코드

from PIL import Image

img = Image.open("photo.jpg")
print(img.size, img.mode, img.format)
(360, 240) RGB JPEG
존재하지 않는 경로나 손상된 파일은 open() 시점이 아니라 픽셀에 처음 접근하는 시점(예: .load(), .save())에 UnidentifiedImageError·OSError가 날 수 있습니다.

Image.new()

지정한 모드·크기·배경색으로 빈 캔버스를 만듭니다. ImageDraw로 도형을 그리거나 여러 이미지를 합성할 때 시작점이 됩니다.

시그니처

Image.new(mode, size, color=0)

파라미터

파라미터설명기본값
mode"RGB" / "RGBA", "L" 등—
size(width, height) 픽셀 튜플—
color배경색. (R,G,B) 튜플, 색 이름 문자열, 또는 정수(그레이스케일)0(검정/투명)

예시 코드

canvas = Image.new("RGB", (300, 200), "white")
print(canvas.size, canvas.getpixel((0, 0)))
(300, 200) (255, 255, 255)
#02

Image.save()

이미지를 파일로 저장합니다. 경로의 확장자로 포맷을 추론하며, format을 명시하면 확장자와 무관하게 강제 지정됩니다.

시그니처

img.save(fp, format=None, **params)

파라미터

파라미터설명기본값
qualityJPEG/WebP 압축 품질(1~95). 높을수록 용량↑ 화질↑JPEG 기본 75
optimizeTrue면 인코더가 더 작은 파일을 위해 추가 연산(느려짐)False
progressiveJPEG를 점진적 로딩 방식으로 저장False
dpi(x, y) 해상도 메타데이터(인쇄용)포맷 기본값

예시 코드

img.save("out.png")                                      # 확장자로 PNG 추론
img.save("out.jpg", quality=85, optimize=True)         # 용량 최적화
img.save("out.webp", format="WEBP", quality=80)
RGBA(투명) 이미지를 JPEG로 저장하면 알파 채널이 없어 에러가 나거나 무시됩니다. 저장 전 img.convert("RGB")로 알파를 제거하세요.

Image.copy()

복사본 반환

완전히 독립된 픽셀 메모리를 가진 사본을 만듭니다. 원본을 보존한 채 paste()·putpixel()처럼 원본을 수정하는 연산을 안전하게 실험할 때 씁니다.

예시 코드

safe = img.copy()
safe.putpixel((0, 0), (255, 0, 0))
print(img.getpixel((0, 0)) == safe.getpixel((0, 0)))
False

Image.resize()

새 이미지

지정한 픽셀 크기로 이미지를 다시 그립니다. 원본 비율을 유지하지 않으므로, 비율을 지키려면 바로 아래의 thumbnail()을 쓰거나 목표 크기를 직접 비율 계산해서 넘겨야 합니다.

시그니처

img.resize(size, resample=Resampling.BICUBIC, box=None)

파라미터

파라미터설명기본값
size 필수목표 (width, height) 픽셀—
resample보간 필터. NEAREST(빠름·계단현상) / BILINEAR / BICUBIC(기본, 매끄러움) / LANCZOS(다운스케일 품질 최상)BICUBIC
box원본에서 리사이즈할 부분 영역(선택)None(전체)

예시 코드

resized = img.resize((160, 160))   # 원본 비율(360x240) 무시 → 정사각으로 찌그러짐
print(resized.size)
(160, 160)
비율을 유지하지 않고 강제로 크기를 맞추므로 사진이 찌그러질 수 있습니다. 썸네일처럼 비율을 지키며 축소하려면 thumbnail()을 쓰세요.
#08

Image.thumbnail()

원본 수정(in-place)

resize()와 달리 가로세로 비율을 유지하면서 지정한 크기 안에 들어가도록 축소합니다. 원본보다 키우지는 않으며, 이미지 객체 자체를 그 자리에서 수정하고 None을 반환합니다.

시그니처

img.thumbnail(size, resample=Resampling.BICUBIC, reducing_gap=2.0)

예시 코드

th = img.copy()
th.thumbnail((160, 160))   # (160,160) '안에' 들어가도록, 비율은 유지
print(th.size)
(160, 107)
갤러리·목록용 미리보기를 만들 때는 거의 항상 resize()가 아니라 thumbnail()이 정답입니다.

Image.rotate()

새 이미지

반시계 방향으로 angle도만큼 회전합니다. expand=False(기본)이면 원본 캔버스 크기를 유지해 모서리가 잘리고, expand=True면 회전된 전체가 보이도록 캔버스를 넓힙니다.

예시 코드

#17

Image.transpose()

새 이미지

90도 단위 회전·반전을 rotate()보다 빠르고 화질 손실 없이 처리합니다. PIL.Image.Transpose 열거형 상수를 인자로 받습니다.

파라미터

상수동작
Transpose.FLIP_LEFT_RIGHT좌우 반전(거울)
Transpose.FLIP_TOP_BOTTOM상하 반전
Transpose.ROTATE_90 / 180 / 27090도 단위 회전(화질 손실 없음)

예시 코드

mirrored = img.transpose(Image.Transpose.FLIP_LEFT_RIGHT)
rotate(90)과 transpose(Transpose.ROTATE_90)은 결과가 같지만, transpose는 재샘플링이 없어 더 빠르고 화질 손실이 없습니다. 90도 단위 회전은 항상 transpose를 우선 고려하세요.

Image.split() · Image.merge()

split()은 각 채널을 독립된 "L" 모드 이미지들의 튜플로 분리하고, merge()는 그 반대로 채널들을 다시 하나의 이미지로 합칩니다. 채널 순서를 바꾸거나 한 채널만 조작할 때 씁니다.

예시 코드

r, g, b = img.split()

Image.point()

새 이미지

모든 픽셀(밴드별)에 함수 또는 256개 값의 룩업테이블을 적용합니다. 반전·임계값(threshold)·감마 보정처럼 픽셀 단위 수식 변환에 putpixel 반복문보다 훨씬 빠릅니다.

예시 코드

inverted = img.point(lambda p: 255 - p)   # 색 반전(네거티브)
ImageOps.invert(img)도 같은 결과를 주는 더 짧은 표현입니다. point()는 반전 외에 임의의 수식·룩업테이블을 쓸 수 있다는 점에서 더 범용적입니다.
#14

Image.getpixel() · Image.putpixel()

원본 수정(putpixel)

좌표 하나의 픽셀 값을 읽거나(getpixel) 씁니다(putpixel). 둘 다 파이썬 반복문으로 대량 호출하면 느리므로, 이미지 전체를 다뤄야 한다면 numpy 변환이나 point()가 훨씬 빠릅니다.

예시 코드

print(img.getpixel((0, 0)))
img.putpixel((0, 0), (255, 0, 0))   # 원본을 직접 수정
(120, 170, 230)
수백×수백 픽셀 이상 이미지에서 putpixel을 이중 for문으로 돌리면 순수 파이썬 오버헤드 때문에 매우 느립니다. np.array(img)로 바꿔 벡터 연산 후 Image.fromarray()로 되돌리는 편이 수십~수백 배 빠릅니다.

Image.filter() · ImageFilter

새 이미지

ImageFilter 모듈의 커널 인스턴스를 filter()에 넘겨 컨볼루션 기반 효과를 적용합니다. 자주 쓰는 것은 GaussianBlur(radius)와 경계 검출 계열입니다.

파라미터

필터설명
ImageFilter.GaussianBlur(radius=2)가우시안 흐림. radius가 클수록 강하게 흐려짐

예시 코드

from PIL import ImageFilter

blurred = img.filter(ImageFilter.GaussianBlur(radius=4))
edges = img.convert("L").filter(ImageFilter.FIND_EDGES)
#10

ImageEnhance.Brightness · Contrast · Color · Sharpness

4개 클래스 모두 같은 패턴입니다 — 생성자에 이미지를 넣고 .enhance(factor)를 호출합니다. factor=1.0은 원본과 동일, 0은 해당 속성이 완전히 빠진 상태(예: Color(0) = 완전 흑백), 1보다 크면 그만큼 강조됩니다.

예시 코드

from PIL import ImageEnhance

bright = ImageEnhance.Brightness(img).enhance(1.6)   # 60% 더 밝게
vivid = ImageEnhance.Color(img).enhance(2.2)        # 채도 2.2배
#19

ImageOps.autocontrast() 외

ImageOps는 ImageEnhance보다 더 자동화된 보정 함수 모음입니다. 대비가 낮은 사진을 히스토그램 기준으로 자동 보정하는 autocontrast()가 가장 자주 쓰입니다.

파라미터

함수설명
ImageOps.autocontrast(image, cutoff=0)가장 어두운/밝은 cutoff%를 잘라내고 나머지로 대비를 최대로 늘림
ImageOps.grayscale(image)convert("L")과 동일한 흑백 변환
ImageOps.mirror(image) / flip(image)좌우/상하 반전(transpose의 간편 버전)
ImageOps.exif_transpose(image)EXIF 방향 태그를 읽어 자동으로 올바르게 회전

예시 코드

from PIL import ImageOps

flat = ImageEnhance.Contrast(img.convert("L")).enhance(0.35)  # 대비를 일부러 낮춤
fixed = ImageOps.autocontrast(flat)                              # 자동으로 대비 복원
스마트폰 사진은 세로로 찍어도 EXIF 방향 태그만 세로로 기록되고 실제 픽셀은 가로로 저장되는 경우가 흔합니다. 업로드받은 이미지를 처리하기 전에 ImageOps.exif_transpose(img)를 먼저 통과시키는 습관을 들이세요.

#09

Image.paste()

원본 수정

다른 이미지를 현재 이미지 위 지정 위치에 붙입니다. mask를 함께 주면(보통 RGBA 이미지 자신의 알파 채널) 투명한 부분은 배경이 비쳐 보이도록 합성됩니다.

시그니처

img.paste(im, box=None, mask=None)

예시 코드

logo = Image.new("RGBA", (80, 80), (0, 0, 0, 0))
d = ImageDraw.Draw(logo)
d.ellipse([4, 4, 76, 76], fill=(255, 60, 60, 220))

base = img.convert("RGBA")
base.paste(logo, (base.width - 100, base.height - 100), logo)   # logo를 마스크로도 사용
mask를 생략하면 logo의 투명 영역(알파 0인 부분)까지 불투명한 사각형째로 덮어써 버립니다. RGBA 이미지를 자연스럽게 합성하려면 im 자신을 mask로도 넘기는 것을 잊지 마세요.

Image.alpha_composite() · Image.blend()

새 이미지

paste()가 국소적인 붙여넣기라면, 이 둘은 같은 크기의 이미지 두 장 전체를 합성합니다. alpha_composite는 두 RGBA를 정확한 알파 규칙으로 겹치고, blend는 단순 가중 평균(alpha 비율)입니다.

시그니처

Image.alpha_composite(im1, im2) / Image.blend(im1, im2, alpha)

예시 코드

a = img.convert("RGBA")
b = img.rotate(180).convert("RGBA")
mixed = Image.blend(a, b, alpha=0.5)   # 50:50 가중 평균
alpha_composite·blend 모두 두 이미지의 크기와 모드가 정확히 같아야 합니다. 크기가 다르면 먼저 resize()로 맞추세요.

Image.putalpha()

예시 코드

rgba = img.resize((220, 150)).convert("RGBA")
rgba.putalpha(140)   # 0(완전 투명) ~ 255(완전 불투명)

#12

np.array(img) · Image.fromarray()

Pillow 이미지와 numpy 배열은 서로 변환이 자유롭습니다. 픽셀 단위 대량 연산(필터링·통계·머신러닝 전처리)은 putpixel 반복문 대신 numpy로 벡터화하는 것이 훨씬 빠릅니다.

예시 코드

import numpy as np

arr = np.array(img)              # (H, W, C) 형태의 uint8 배열
print(arr.shape, arr.dtype)

darker = (arr * 0.6).astype(np.uint8)   # 전체 픽셀을 한 번에 어둡게
result = Image.fromarray(darker)
(240, 360, 3) uint8
numpy는 (height, width, channels) 순서, Pillow의 .size는 (width, height) 순서입니다. 서로 변환할 때 축 순서를 헷갈리지 않도록 주의하세요.
#20

Image.getexif()

카메라·스마트폰이 기록한 EXIF 메타데이터(촬영 방향, 날짜, 카메라 모델 등)를 dict처럼 읽습니다. 방향 태그(0x0112)는 앞서 소개한 ImageOps.exif_transpose()와 짝을 이룹니다.

예시 코드

exif = img.getexif()
for tag_id, value in exif.items():
    print(tag_id, value)
JPEG가 아닌 포맷(PNG 등)이거나 메타데이터가 없는 이미지는 빈 Exif 객체가 반환됩니다 — None이 아니라 길이 0인 dict-like 객체이므로 if exif:로 존재 여부를 확인하세요.

BytesIO로 메모리에 저장

디스크에 파일을 쓰지 않고 메모리 버퍼에 인코딩된 이미지 바이트를 만듭니다. 웹 API 응답, 업로드, DB 저장처럼 파일 시스템을 거치지 않아야 하는 상황에 씁니다.

예시 코드

import io

buf = io.BytesIO()
img.save(buf, format="PNG")
data = buf.getvalue()          # bytes — 그대로 HTTP 응답 body 등에 사용
print(len(data), "bytes")

자주 쓰는 속성 .size · .mode · .format · .width/.height

메소드가 아니라 속성이므로 괄호 없이 접근합니다. 조건 분기·로깅·검증에 가장 자주 등장합니다.

파라미터

속성설명
.size(width, height) 튜플
.width / .height.size의 각 요소와 동일(더 읽기 쉬움)
.mode현재 컬러 모드 문자열
.formatopen()으로 열었을 때의 원본 포맷("JPEG" 등). Image.new()로 만들면 None

예시 코드

if img.mode != "RGB":
    img = img.convert("RGB")
print(f"{img.width}x{img.height}, {img.format}")
360x240, JPEG

포맷별 저장 옵션 요약

같은 save()라도 포맷에 따라 받는 키워드 인자가 다릅니다. 실무에서 자주 부딪히는 세 포맷만 정리합니다.

포맷주요 옵션용도
JPEGquality(1~95), optimize, progressive사진. 알파 채널 저장 불가
PNGoptimize, compress_level(0~9)무손실, 알파 채널·스크린샷·아이콘
WEBPquality, losslessJPEG/PNG보다 대체로 더 작은 용량
웹 서비스에서 사용자 업로드 이미지를 재저장할 때는 JPEG(quality=85, optimize=True) 또는 WEBP(quality=80) 조합이 용량 대비 화질 균형이 좋아 자주 쓰입니다.
